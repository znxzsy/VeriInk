# RSI 工作流：可验证合成

VeriInk 为外部管理的模型迭代提供可控练习。公开可执行范围是固定 seed 渲染与产物检查。

## 具体交接

- 输入：经人工复核的需求、`SlotSpec` 与 seed。
- 生成：运行 `python scripts/generate_demo.py`，得到公开合成图库。
- 检查：`examples/gallery/manifest.json` 记录路径、seed、可见答案、转写、检查字段与图片哈希；`verify_gallery` 检查存储合同，视觉语义仍需审核。
- 交接：领域适配器可将选中的图片及外部批改模型输出转换为 AlignLedger 导入格式；该映射未内置，两类 manifest 不能直接互换。
- 使用：外部流程冻结训练选择并独立评估训练结果，渲染器不负责选择 checkpoint。

## 决策与证据

1. 审核／发现数据与评测数据分别管理，训练前定义题源或组级隔离规则；这两个仓库不负责全研究范围的防泄漏检查。
2. 保留未知和拒绝样本。模型失败可能来自练习不足、证据模糊或标签错误，不能自动推导为生成器缺少能力。
3. 合法数据能力是否保留、训练 checkpoint 是否采用，分别决定。文件哈希与软件测试通过均不能证明模型收益或真实场景迁移。
4. 固定基线、声明预算，保留负结果；在适当隔离的评测上完成比较后再考虑晋升。

## 公开边界

这是由人指导的数据工作流。两个仓库之间的自动连接、递归训练器、自主代码生成 Agent、研究验证器和模型晋升控制器均不在公开版内。下述虚构记录没有操作权限，也不是实验回执。研究核心源码、提示词、私有数据和模型权重不在这两个仓库公开。
