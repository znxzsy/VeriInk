# 安全与数据边界 / Security and Data Boundary

VeriInk 公开仓库只包含仿真演示数据。

The public VeriInk repository contains synthetic demo data only.

- 不含真实学生图片或标注 / No real student images or annotations
- 不含凭证、内部地址、对象存储路径或真实配置 / No credentials, internal endpoints, object-storage paths, or real configuration
- 不含生产采样分布或私有质量阈值 / No production sampling distributions or proprietary quality thresholds
- 不含模型 checkpoint 或训练数据集 / No model checkpoints or training datasets

请勿在公开 Issue 中提交私有数据。安全或数据边界问题请通过微信 `znxzsy` 私下联系维护者。

Do not open a public issue containing private data. For security or data-boundary concerns, contact the maintainer privately through WeChat `znxzsy`.
