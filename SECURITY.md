# Security and data boundary

The public VeriInk repository contains synthetic demo data only.

- No real student images or annotations
- No credentials, internal endpoints, object-storage paths, or real configuration
- No production sampling distributions or proprietary quality thresholds
- No model checkpoints or training datasets

Do not open a public issue containing private data. For security or data-boundary concerns, contact the maintainer privately through WeChat `znxzsy`.
